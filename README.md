# Aprendiendo Java

Repositorio personal donde recopilo mi progreso durante el aprendizaje de Java, como parte de mis estudios del Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW).

Aquí encontrarás ejercicios y prácticas que voy realizando para poner en práctica los conocimientos adquiridos durante mi formación.

## Contenido

Los ejercicios están organizados por bloques temáticos:

1. **Fundamentos:** conceptos básicos del lenguaje Java.
2. **Estructuras de control:** ejercicios sobre condicionales y bucles.
3. **Métodos:** creación y utilización de métodos.
4. **Programación orientada a objetos:** conceptos fundamentales de la programación orientada a objetos.
5. **Arrays y colecciones:** almacenamiento y manipulación de datos.
6. **Otros contenidos:** nuevos conceptos y ejercicios que vaya incorporando durante mi formación.

_El contenido se irá modificando a medida que avance en mi aprendizaje._

## Tecnologías y herramientas
* **Java:** lenguaje de programación.
* **JDK:** entorno de desarrollo de Java.
* **Eclipse IDE:** entorno de desarrollo utilizado para programar.
* **Git y GitHub:** control de versiones y alojamiento del repositorio.

## Objetivo

Documentar mi evolución, practicar los conceptos aprendidos y mantener un registro de mi progreso durante mi formación como futura desarrolladora web.

_Repositorio en constante evolución._
